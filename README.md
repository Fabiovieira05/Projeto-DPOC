## 📝 Sobre o Projeto

Este repositório contém o código-fonte da plataforma educativa sobre a Doença Pulmonar Obstrutiva Crônica (DPOC). O projeto compõe a avaliação estruturada do Módulo 2 da disciplina de Cuidado do Adulto e do Idoso, ministrada no Departamento de Enfermagem da Faculdade de Ciências da Saúde da Universidade de Brasília.

A plataforma foi projetada para ter um layout limpo, organizado e um design totalmente responsivo para celulares e tablets. A perspectiva a longo prazo é apresentar a aplicação no evento de Gestão de Tecnologia em Saúde, previsto para novembro de 2026, e hospedá-la oficialmente na plataforma do NESPROM/CEAM/UnB.

## 🎯 Objetivo

Traduzir conhecimento científico rigoroso em conteúdo claro e acessível. O site foca na promoção da saúde, na prevenção e no manejo clínico da DPOC, estimulando o autocuidado e o empoderamento do paciente, além de mapear a rede de assistência pública no Distrito Federal.

## 📚 Conteúdo Abordado

A arquitetura de informação do site segue uma abordagem conceitual direta, englobando os seguintes pilares fundamentais:

* **Introdução e Epidemiologia:** Dados epidemiológicos atualizados sobre o impacto da doença no Brasil.
* **Quadro Clínico:** Identificação de sintomas e métodos de diagnóstico.
* **Riscos e Prevenção:** Fatores de risco, principais complicações e meios de prevenção e controle.
* **Gestão da Doença:** Monitoramento clínico e estratégias de adesão ao tratamento.
* **Educação em Saúde:** Desmistificação de mitos e verdades comuns sobre a doença.
* **Cuidado Integral:** Cuidados de Enfermagem preventivos e promotores de saúde (tratamentos não farmacológicos).
* **Terapias Complementares:** Práticas Integrativas relacionadas à DPOC.
* **Acesso à Saúde:** Mapeamento de onde encontrar a rede de apoio no DF.

## 🛠️ Tecnologias Utilizadas

A aplicação web utiliza as tecnologias que aplicamos no ecossistema de desenvolvimento frontend para garantir alta performance e manutenibilidade:

* **Framework:** Next.js (App Router)
* **Estilização:** Tailwind CSS
* **Linguagem:** TypeScript

## 🚀 Como Executar o Projeto

Siga os passos abaixo para rodar a aplicação localmente no seu ambiente de desenvolvimento:

1. Clone o repositório:
```bash
git clone [https://github.com/seu-usuario/nome-do-repositorio.git](https://github.com/seu-usuario/nome-do-repositorio.git)
```

2. Acesse o diretório do projeto:
```bash
cd nome-do-repositorio
```

3. Instale as dependências:
```bash
npm install
```

4. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

5. Abra `http://localhost:3000` no seu navegador para ver o resultado.
